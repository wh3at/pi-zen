# pi-zen

piの標準ツール表示を、作業の足跡を追える最小限の表示へ置き換えるpi extensionです。

- 対象: `read` / `write` / `edit` / `bash` / `grep` / `find` / `ls`
- 表示: `状態 → ツール名 → 対象 → ツール差分数（edit成功時のみ）`
- 標準tool factoryへ実行を委譲し、モデル向け結果や保存内容は変更しません。
- 画像readはpi標準の画像表示経路と設定を維持します。

## インストール

```bash
pi install git:github.com/wh3at/pi-zen
```

最低対応piバージョンは0.85.1です。同名ツールを置き換える別extensionとの併用は保証対象外で、pi-zenより先に登録済みの同名ツールは上書きしません。

## 確認記録

2026-04-02時点でnpmの最新安定版は0.85.1であり、最低対応版と同一です。0.85.1を依存関係として読み込み、公開`bindExtensions`で起動イベントを配送したSDKセッションで、有効ツール集合の維持、標準edit/readへの委譲、結果content/detailsと標準prompt metadataの維持、保存済み引数・結果による再開相当の完了表示、複数行コマンドの1行化、日本語パス・コマンド・失敗理由の幅制限を自動試験しました。

実対話TUIでの40/64/100桁、画像、全7ツールの成功・失敗、並行実行、リサイズ、中断、実会話の再開、reloadの受け入れ確認は未実施です。JSON/RPCプロセスを起動したE2E確認も未実施で、SDKセッションで結果非改変を確認しています。

pi 0.85.1では、内容があるツール表示の先頭にpi側が空行を1行追加します。Issue #6の空行禁止要件は撤回され、この空行は許容されます。通常1行・失敗最大2行の制限は要約と失敗理由の本文に適用し、pi側の空行は数えません。枠・背景色を付けない要件は維持します。
